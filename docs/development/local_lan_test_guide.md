# 本地局域网测试说明

## 1. 场景说明
由于学校VPN的特殊性，建议使用手机热点将开发电脑和终端设备连接到同一个局域网，避免VPN对内网通信的影响，保证设备间互通。

## 2. 操作步骤

1. **手机开启热点**，让“开发电脑”和“终端设备”都连接到该热点。
2. 在开发电脑上打开命令行，输入 `ipconfig`，找到“无线局域网适配器 WLAN”下的 `IPv4 地址`（如 `192.168.43.101`）。
3. 启动后端服务（如Spring Boot默认端口8080）。
4. 在终端设备或浏览器访问时，将 `http://localhost:8080` 替换为 `http://你的IPv4地址:8080`，如 `http://192.168.43.101:8080`。
5. WebSocket等服务同理，地址中的 `localhost` 也要替换为你的本机IPv4地址。

## 3. 注意事项
- 确保防火墙允许外部设备访问对应端口（如8080、8443等）。
- 终端和电脑必须都连在同一个热点下，且在同一网段。
- 若访问不通，可尝试关闭电脑的防火墙或添加端口放行规则。
