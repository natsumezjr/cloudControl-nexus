# 服务器启动说明

## 批处理文件（推荐使用）

### 1. 开发环境
```bash
start_dev_server.bat
```

### 2. 测试环境
```bash
# 清理数据库并启动
start_test_server.bat

# 不清理数据库直接启动
start_test_server_not_clean_database.bat
```

### 3. 数据库重置
```bash
reset_test_db.bat
```

### 4. 通用启动脚本
```bash
# 开发环境
start_server.bat dev

# 测试环境（清理数据库）
start_server.bat test

# 测试环境（不清理数据库）
start_server.bat test-noclean
```

## PowerShell文件（备用）

如果批处理文件有问题，可以使用PowerShell文件：
- `start_dev_server.ps1`
- `start_test_server.ps1`
- `start_test_server_not_clean_database.ps1`
- `reset_test_db.ps1`

## 编码问题解决

所有批处理文件都已配置UTF-8编码，确保中文显示正常。

## 环境要求

- Java 17+
- Maven 3.6+
- PostgreSQL 12+
- Redis（可选）

## 访问地址

- 开发/测试环境：http://localhost:8080
- API文档：http://localhost:8080/swagger-ui.html
- 健康检查：http://localhost:8080/actuator/health
